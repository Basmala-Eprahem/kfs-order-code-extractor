# استخراج كود الطلب من شهادات نظم المعلومات الجيومكانية (OCR)

تطبيق ويب بلغة Python (Flask + OpenCV + Tesseract) لاستخراج قيمة **«كود الطلب»**
الرقمية من صور شهادات التقييد / التراخيص الصادرة عن مركز نظم المعلومات الجيومكانية.

## المزايا

- **تصحيح الاتجاه تلقائيًا** بالتجربة على الاتجاهات (0/90/180/270) واختيار
  الأنسب حسب جودة القراءة العربية.
- **استخراج الرقم المجاور لكلمة `كود الطلب` فقط** (لا تظهر أرقام أخرى طويلة):
  البحث عن التسمية (بأشكال قراءة متعددة) وقراءة الرقم الموجود في خليتها مباشرة.
- واجهة ويب عربية بسيطة: **ارفع الصورة واحصل على النتيجة**، مع معاينة الصورة بعد
  تصحيح الاتجاه.
- إذا لم يُعثر على الرقم تُعرض رسالة واضحة (جودة مسح ضعيفة/تسمية غير واضحة)
  بدل أرقام أخرى.
- سكربت تقييم ينتج `outputs/extraction_results.csv` وملخصًا إحصائيًا.
- **معالجة دفعة كاملة**: اختيار عدة صور (حتى آلاف)، استخراج الكود من كل صورة،
  إعادة التسمية بالكود مع الحفاظ على صيغة الملف الأصلية، حفظ الفاشل في `failed/`,
  ثم تنزيل `ZIP` واحد يحتوي الصور المعاد تسميتها + مجلد الفاشل + `results.csv`.

## معالجة الدفعات (ويب)

1. في صفحة «معالجة دفعة كاملة» اختر عدة صور (يمكن السحب والإفلات).
2. اضغط «بدء المعالجة» وتابع النسبة المئوية والأعداد (نجاح/فشل).
3. عند اكتمالها اضغط «تنزيل ZIP».

السلوك:
- كل صورة تُعالج منفردة عبر نفس خط أنابيب OCR (تلقائي الحالي) ولا يُحمَّل شيء في
  الذاكرة دفعة واحدة (تُحفظ الملفات على القرص وتُقرأ صورة-صورة).
- يُعدّ الكود **6 أرقام فقط** ناجحًا؛ ما عدا ذلك (لم يُعثر، ملف تالف، صيغة غير
  مدعومة، خطأ OCR) يذهب إلى `failed/` باسمه الأصلي، وتمرّ الدفعة للصورة التالية.
- صيغ الملفات: يُحدَّد النوع الفعلي من محتوى الملف (Magic Bytes) وليس من
  الامتداد، ويُحفظ الامتداد الأصلي عند إعادة التسمية
  (مثلًا `col.png` → `329918.png`, `col.webp` → `331450.webp`).
  الصيغ المدعومة: JPG/JPEG/PNG/WEBP/BMP/TIFF/GIF (HEIC/HEIF تُكتشف كصورة
  وتُحفظ بامتدادها ولكن فكها للنص يتطلب دعم النظام).
- الأكواد المكررة لا تُحذف ولا تُستبدل: `123456.jpg`, `123456_1.png`, ...
- النتائج: `original_filename, final_filename, extracted_code, status, error_message`
  في `results.csv` داخل الـ ZIP وتُحفظ نسخة في `outputs/batches/<id>.csv` والـ ZIP
  في `outputs/batches/<id>.zip`.
- كل دفعة في مجلد مؤقت خاص بها (`uploads/batch/<id>/`) يُنظف بعد إنشاء الـ ZIP.

## الاختبار

```powershell
& .\venv\Scripts\python.exe scripts\smoke_flask.py   # الوضع المفرد
& .\venv\Scripts\python.exe scripts\test_batch.py    # الدفعات (صيغ/مكرر/تالف/1000+)
```

## المتطلبات

- Python 3.10+ مع virtualenv (`venv/` موجود هنا وجاهز).
- [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) مثبّت مع لغات
  `ara` و `eng`. المسار الافتراضي في `config.py` هو `C:\Program Files\Tesseract-OCR\tesseract.exe`.

## التشغيل

```powershell
# تثبيت المتطلبات (مرة واحدة)
& .\venv\Scripts\python.exe -m pip install -r requirements.txt

# تشغيل الويب
& .\venv\Scripts\python.exe run.py
# ثم افتح المتصفح على http://127.0.0.1:5000
```

## البنية

```
app/
  __init__.py          factory
  routes.py            مسارات الويب (رفع / استخراج / معاينة / دفعات)
  services/
    extractor.py       منطق الاستخراج (لا يعتمد على Flask)
    batch.py           معالجة الدفعات: اكتشاف الصيغ، إعادة التسمية، CSV، ZIP
  templates/           index.html, result.html
  static/css,js        الواجهة
config.py              كل الإعدادات (المسارات، Tesseract، النمط المتوقع)
scripts/
  analyze_dataset.py   تحليل الصور ومعلومات الأبعاد والاتجاهات
  evaluate_dataset.py  تشغيل الاستخراج على الصور وإنتاج تقرير
  smoke_flask.py       اختبار الوضع المفرد
  test_batch.py        اختبار الدفعات (صيغ / مكرر / تالف / 1000+)
run.py                 نقطة تشغيل التطبيق
images/                مجموعة الصور (لا تتعدل أبدًا)
outputs/               تقارير ومعاينات مولّدة + ZIP/CSV الدفعات
uploads/               صور مرفوعة مؤقتة (منفصلة لكل دفعة)
```

## مفاتيح الإعداد (`config.py`)

| المفتاح | الوصف |
| --- | --- |
| `TESSERACT_CMD` | مسار tesseract.exe |
| `OCR_LANGS` | لغات OCR (`ara+eng`) |
| `TARGET_FIELD_NAME` | التسمية المستهدفة: `كود الطلب` |
| `EXPECTED_NUMBER_PATTERN` / `FALLBACK_CODE_PATTERN` | نمط القيمة المتوقع/الاحتياطي |
| `MAX_CONTENT_LENGTH` | حد حجم الرفع (20MB) |
| `MAX_IMAGE_SIDE` / `PROCESS_SIDE` | حدود تحجيم الصور |

## نتيجة الاستخراج

لكل صورة تُحفظ في `outputs/extraction_results.csv`:
`filename, orientation, label, method, value, processing_ms`

## ملاحظات معلومة من تحليل البيانات

- مجموعة الصور غير متجانسة: 658 صورة بنمط `1 (xxx).jpg` هي شهادات «شهادة تسجيل
  مكاني / قيد ارتفاع» تحمل التسمية `كود الطلب`، وتظهر قيمتها كرقم طويل يبدأ بـ
  `015` (مثل `015080022037437`).
- صور أخرى قد تكون تراخيص بناء أو نسخًا مختلفة قد لا تتضمن التسمية بوضوح،
  وفيها لن تُعرض قيمة.
- بعض السكانات تالف في خلية الكود نفسه (الأرقام غير قابلة للقراءة حتى بتكبير
  الخلية)، فلا يمكن استخراج القيمة منها آليًا.
- لا توجد حزمة إجابات (ground truth)، لذا يقيس سكربت التقييم نسبة نجاح العثور على
  القيمة المجاورة للتسمية فقط.
